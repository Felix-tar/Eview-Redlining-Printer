# eVIEW Redlining Print Assistant

Eine Browser-Erweiterung für Microsoft Edge, die eVIEW-Seiten mit Redlining-Anmerkungen automatisch erkennt, die passenden Seiten erfasst und für einen gemeinsamen Druck im A4-Querformat vorbereitet.

Die Erweiterung arbeitet innerhalb der bereits geöffneten eVIEW-Umgebung und benötigt einen gültigen eVIEW-Zugang.

## Manuelle Installation in Microsoft Edge

1. Dieses GitHub-Repository herunterladen:  
   **Code → Download ZIP**

2. ZIP-Datei entpacken.

3. In Microsoft Edge folgende Seite öffnen:

   `edge://extensions/`

4. **Entwicklermodus** aktivieren.

5. Auf **Entpackte Erweiterung laden** klicken.

6. Den entpackten Ordner auswählen, in dem sich die Datei `manifest.json` befindet.

7. Die Erweiterung bei Bedarf über das Erweiterungsmenü an die Edge-Symbolleiste anheften.

## Verwendung

1. eVIEW öffnen und ein Projekt bzw. eine Zeichnung laden.
2. Den **eVIEW Redlining Print Assistant** öffnen.
3. Gewünschte Redlining-Filter auswählen.
4. Redlining-Seiten erfassen.
5. Warten, bis die Seiten vollständig verarbeitet wurden.
6. Die erfassten Seiten gemeinsam drucken.

Die Erweiterung optimiert während der Erfassung automatisch die eVIEW-Darstellung, unter anderem durch Vollbilddarstellung und 100-%-Zoom, damit die Zeichnungen möglichst groß und sauber gedruckt werden.

# English

# eVIEW Redlining Print Assistant

A Microsoft Edge browser extension that automatically detects eVIEW pages containing redlining annotations, captures the relevant pages, and prepares them for combined A4 landscape printing.

The extension works inside an already opened eVIEW environment and requires a valid eVIEW account.

## Microsoft Edge Add-ons

**Microsoft Edge Add-ons Store:**  
The public store link will be added here once the extension has been approved by Microsoft.

## Manual installation in Microsoft Edge

1. Download this GitHub repository:  
   **Code → Download ZIP**

2. Extract the ZIP file.

3. Open the following page in Microsoft Edge:

   `edge://extensions/`

4. Enable **Developer mode**.

5. Click **Load unpacked**.

6. Select the extracted folder that contains the `manifest.json` file.

7. If desired, pin the extension to the Edge toolbar using the Extensions menu.

## Usage

1. Open eVIEW and load a project or drawing.
2. Open the **eVIEW Redlining Print Assistant**.
3. Select the required redlining filters.
4. Start capturing the redlining pages.
5. Wait until all pages have been processed.
6. Print the captured pages together.

During capture, the extension automatically optimizes the eVIEW display, including fullscreen mode and 100% zoom, so that drawings can be printed as large and cleanly as possible.

## Privacy

The extension processes the eVIEW content required for its functionality locally in the browser and does not transmit eVIEW document pages or login credentials to developer-operated servers.
